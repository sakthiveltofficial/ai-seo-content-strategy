# Self-Critique Protocol — Iterative Content Refinement

Mandatory editorial quality gate before any content is declared 'final'. The score is an internal heuristic—not a Google metric, ranking score, or prediction of organic traffic or AI citations.

## The 11-Dimension Scoring Framework

Score each dimension 1-10:

| Dimension | What It Measures | Weight |
|-----------|-----------------|--------|
| SEO Strategy | Keyword targeting, SERP opportunity capture | 10% |
| Keyword Targeting | Primary/secondary/long-tail coverage density | 8% |
| Search Intent | Match between content and searcher's actual intent | 10% |
| AI-Native Positioning | Clarity of AI-native vs traditional differentiation | 10% |
| Competitive Differentiation | How clearly content stands apart from competitors | 8% |
| Content Quality | Writing quality, humanization, technical credibility | 12% |
| E-E-A-T / Proof | Concrete evidence, real examples, verifiable claims | 12% |
| GEO / AI-Search Readiness | Citation-ready format, entity clarity, structured data | 10% |
| Internal-Link Architecture | Link density, anchor diversity, equity flow | 5% |
| Conversion Potential | CTA specificity, value-first framing, funnel alignment | 10% |
| Technical SEO | Meta tags, schema, heading structure, URL optimization | 5% |

## Scoring Rules
- Overall = weighted average of all 11 dimensions. Explain evidence behind scores; do not assign precision the evidence cannot support.
- Editorial target: 8.5/10 overall, no dimension below 7.0. This is an internal editorial standard, not an SEO performance guarantee.
- If below threshold: revise and re-score (max 3 cycles). A critical factual, safety, copyright, permission, or technical blocker overrides the average.
- Distinguish `Verified`, `User-provided`, `Inferred`, and `Unknown` proof. Do not give E-E-A-T credit for a claim without checking whether the evidence is real, allowed for publication, and attributable.
- Treat the local content scorer as a linting aid. Review and waive false positives caused by page type or brief; do not add FAQ/schema/word-count requirements when the approved brief does not call for them.
- Before a final publish recommendation, confirm source links, metrics, claims, target market, page intent, correct internal URLs, and any technical audit checks that are in scope.

## Common V1 Failures (from Webnox Digital project)
1. Trust/credibility too low (6.5/10) — Fix: add proof-before-pitch section
2. Readability too dense (6.5/10) — Fix: shorter paragraphs, more whitespace
3. Self-proclaimed titles — Fix: remove ALL 'premier/leading/#1' language
4. Fake statistics — Fix: remove unverifiable claims, use operational benchmarks
5. Hero sells company not value — Fix: add 'What You Get' box
6. Equal weight on all services — Fix: center-of-gravity rule
7. Comparison table brand harm — Fix: generic competitor labels
8. Too many AI buzzwords — Fix: reduce 'autonomous/agentic/next-generation' density
